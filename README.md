Built with an immersive **Cyber-Neon 3D WebGL particle environment**, this tool provides real-time comparative analysis between **Traditional FIFO TLB** replacement and a modern **DEPOT-Inspired Dead-Entry Protection Architecture**.

## 🧠 Background & Operating System Concepts

### 1. Paging & Address Translation
In modern virtual memory architectures, virtual addresses generated by the CPU are split into a **Virtual Page Number (VPN)** and an **Offset**. To access physical memory (RAM), the operating system must translate the VPN into a **Physical Frame Number (PFN)** using a **Page Table**.

### 2. What is a TLB (Translation Lookaside Buffer)?
Because page tables are stored in main memory, every memory reference would theoretically require two memory accesses (one for the page table, one for the actual data/instruction). 
The **TLB** is a fast, hardware associative cache that holds recent VPN-to-PFN translations:
- **TLB Hit**: The translation is cached. Memory access requires only:
  $$\text{Access Time} = t_{\text{TLB}} + t_{\text{mem}}$$
- **TLB Miss**: The translation is missing. Hardware or OS must walk the page table in main memory, reload the entry into the TLB, and then perform the target memory access:
  $$\text{Access Time} = t_{\text{TLB}} + 2 \times t_{\text{mem}}$$

### 3. Effective Access Time (EAT)
Let $\alpha$ be the TLB Hit Ratio ($0 \le \alpha \le 1$), $t_{\text{TLB}}$ be the TLB lookup latency, and $t_{\text{mem}}$ be the main memory access latency. EAT is calculated as:
$$\text{EAT} = \alpha \times (t_{\text{TLB}} + t_{\text{mem}}) + (1 - \alpha) \times (t_{\text{TLB}} + 2 \times t_{\text{mem}})$$

### 4. The "Dead-Entry" Phenomenon & DEPOT Architecture
In traditional FIFO or LRU replacement policies, when the TLB is full, an entry is evicted. If a workload accesses a set of pages slightly larger than the TLB capacity, entries are repeatedly evicted and immediately re-referenced. This causes **Dead-Entry Misses** and severe TLB thrashing.

The **DEPOT-Inspired Policy** incorporated in this simulator introduces:
1. **Recently Evicted History**: Tracks pages that were evicted from the TLB.
2. **Dead-Entry Detection**: Flags when an evicted page is re-requested within a short temporal window.
3. **Protected Partitioning**: Grants temporary eviction protection to recovered dead entries, ensuring they are not chosen as victims during the next cache contention.

## 🖥️ User Interface & Features

| Component | Description |
|---|---|
| **Parameters Panel** | Configure TLB Size, Page Size (KB), TLB Lookup Time ($t_{\text{TLB}}$), Memory Access Time ($t_{\text{mem}}$), and Page Reference Sequence. |
| **Algorithm Modes** | Toggle between **Traditional TLB**, **DEPOT-Inspired**, or **Compare Both**. |
| **Execution Controls** | **Run Simulation** (batch run), **Next Step** (interactive step-by-step walk), and **Reset**. |
| **Trace Table** | Full step-by-step breakdown listing Step #, Page Ref, Result (`HIT`, `NORMAL MISS`, `DEAD-ENTRY MISS`), Current TLB Array, Page Table Access Flag, Evicted Page, Protected Pages, and contextual remarks. |
| **Metrics Summary** | Displays total page references, hit/miss tallies, dead-entry misses, hit ratio %, and calculated EAT in nanoseconds. |
| **Comparison Chart** | Interactive bar chart visualizing the performance differences between Traditional and DEPOT algorithms. |
| **OS Concepts Panel** | Scrollytelling card summarizing core operating system definitions for students and developers. |

## ⚡ Getting Started

### Prerequisites
All you need is a modern web browser supporting WebGL (Google Chrome, Mozilla Firefox, Microsoft Edge, Safari, Brave, Opera).

### Running Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/Anjali-Furia/TLB-Paging-Hit-Miss-Analyser-GUI-.git
   cd TLB-Paging-Hit-Miss-Analyser-GUI-
   ```
2. Open `index.html` directly in your browser:
   - On Windows: Double-click `index.html` or run:
     ```powershell
     Start-Process index.html
     ```
   - Alternatively, serve via VS Code Live Server or Python HTTP server:
     ```bash
     python -m http.server 8000
     ```

## 🧪 Example Simulation Walkthrough

**Input Parameters:**
- **TLB Size**: `3`
- **Page Size**: `4 KB`
- **TLB Lookup Time ($t_{\text{TLB}}$)**: `10 ns`
- **Memory Access Time ($t_{\text{mem}}$)**: `100 ns`
- **Sequence**: `1 2 3 4 1 2 4 1`

**Observations:**
- **Traditional TLB**: Experiences multiple compulsory and capacity misses with continuous FIFO replacement.
- **DEPOT-Inspired TLB**: Flags re-referenced pages (`1`, `2`, `4`) as **DEAD-ENTRY MISSES**, protects them from consecutive victim selection, and reduces memory thrashing.
