✨ Core OS & Architectural Concepts
TLB Hit: Frame mapping found instantly in cache. Avoids physical memory page table walks[cite: 2].
TLB Miss: Mapping absent. Forces expensive main memory page table access and lookup latency[cite: 3].
Dead-Entry Miss: Evicted page re-requested shortly after, triggering redundant misses[cite: 14].
DEPOT Protection: Guards re-requested dead entries from immediate re-eviction cycles[cite: 14].
